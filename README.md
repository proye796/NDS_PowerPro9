- **원본 게임 버그 수정:** 일본판에 알려진 버그 가운데 13건을 고치고 2건은 일부만 고쳤습니다.
  - 어나더 석세스에 들어가면 사운드 테스트 68번이 해금되도록 했습니다.
  - 남은 날짜가 0일일 때 정해진 이벤트가 랜덤 이벤트에 밀려 취소되던 문제를 고쳤습니다.
  - PP9 패스워드에서 일부 얼굴(144~180번)의 선수가 거부되던 문제를 고쳤습니다.
  - PP8 패스워드로 입력한 선수의 출신 표시를 고쳤습니다.
  - 통신 아이콘이 다음 타자(NEXT) 얼굴을 가리던 문제를 고쳤습니다.
  - 카나와의 축제 이벤트에서 코린트 게임을 한 뒤 경품을 받지 못하던 문제를 고쳤습니다.
  - 육성을 마칠 때 고른 장내 아나운스가 등록 선수에 반영되지 않던 문제를 고쳤습니다.
  - 동료 투수를 강화한 뒤 변화구가 사라지던 문제를 고쳤습니다.
  - 5월 12일 이벤트의 메시지 위치가 어긋나던 문제를 고쳤습니다.
  - 스페이스 캡틴 투수의 구속이 올라도 어깨력이 맞춰지지 않던 문제를 고쳤습니다.
  - 아키미 대사의 말풍선 방향을 고쳤습니다.
  - 슈팅에서 적이 정해진 좌표를 벗어나던 문제를 고쳤습니다.
  - 팀 편집에서 팀을 불러올 때 이전 선수의 오리지널 변화구가 남던 문제를 고쳤습니다.
  - (일부) 협살(런다운) 무한 반복: 주자 방향·송구할 베이스·주루 시간 계산 3곳을 고쳤지만, 무한 반복이 사라졌는지는 확인하지 못했습니다.
  - (일부) 창고가 가득 찼을 때 보상 메시지가 이어지는 문제: 창고 화면에서 돌아온 뒤 대사 위치만 바로잡았습니다.
